# Skills for Engineering

Agent skills for engineering

## 1. Installation
Example: Installing ```kirby-cms``` skill for ```claude-code```, ```cursor``` and ```codex```

```npx skills@latest add baalej/skills --skill kirby-cms --agent claude-code cursor codex --yes```

## 2. Update
Example: Updating ```all``` skills inside a project.

```npx skills@latest update kirby-cms```

Example: Updating ```kirby-cms``` skill.

```npx skills@latest update kirby-cms```
